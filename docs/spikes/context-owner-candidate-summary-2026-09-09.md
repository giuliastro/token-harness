# Context owner candidate summary — 2026-09-09

Savings Engine will not admit a broad context owner merely because it advertises token savings.

Current candidate direction:

- native Codex MCP `tool_search` remains the preferred tool-deferral baseline where effective activation can be proven;
- Headroom is the first external broad-context candidate to benchmark because it has a mature CLI/wrapper model and explicitly understands native tool-search behavior;
- Context Mode remains a comparison candidate, not a default;
- startup-only lazy MCP wrappers that continue to expose the same tool schemas do not qualify as context savers.

The benchmark layer added in this branch exists specifically to measure model-visible context-shape evidence separately from quality, retries, local token usage and backend allowance.

No candidate is enabled by this branch.
