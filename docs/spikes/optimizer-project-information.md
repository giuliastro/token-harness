The guided setup catalogue carries static editorial information, reviewed on 2026-10-04.
Project-reported figures describe their upstream workloads, not predictions for the user's
machine. They are never inputs to metrics, routing savings, allowance attribution or stack
selection. Installation availability still comes from the existing provider/harness contract.

| Project | Published figure used in setup | Scope and source |
| --- | --- | --- |

The mcptoon catalogue link uses the live canonical project `activeing123/mcptoon`;
the historical `mcptoon/mcptoon` manifest URL no longer resolves. Headroom's older
`chopratejas/headroom` URL redirects to `headroomlabs-ai/headroom`. These are editorial
source links, not changes to install channels or admitted versions.
