# Token Harness 0.1.19 — RTK updates on Linux and macOS

`0.1.19` includes RTK update-check and installation fixes for Linux and macOS, plus shadow-first Smart Model Routing.

## What changed

- **RTK updates are found on Linux and macOS.** Token Harness checks RTK's official GitHub release instead of the unrelated `rtk` crate on crates.io.
- **RTK binaries are verified before replacement.** An approved update downloads the matching official release asset and checks its published SHA-256 digest. Windows keeps WinGet as its primary channel and uses the verified GitHub release as a fallback.
- **Smart Model Routing starts in shadow mode.** It records local routing decisions without changing provider calls; conservative routing remains an explicit opt-in.

## Safety

The update flow retains the existing approval, backup, verification and rollback behavior. Issue #255 remains open for before/after receipts from the complete production stack; this incremental release makes no broad-promotion claim.

## Upgrade

```sh
npm install --global token-harness@latest
token-harness
```
