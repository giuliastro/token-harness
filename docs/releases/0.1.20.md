# Token Harness 0.1.20 — Smart Model Routing UI and reliable RTK updates

`0.1.20` is a corrective patch for the two 0.1.19 gaps reported after release: Smart Model Routing is now manageable from the guided browser UI, and RTK 0.44 can be upgraded reliably to the reviewed 0.50.0 release on Linux even when shadowed RTK copies exist on PATH.

## What changed

- **Smart Model Routing is visible in the browser app.** Each detected Claude Code or Codex installation gets an explicit Smart Model Routing section. The normal flow starts in **shadow mode**, which classifies requests locally and records decisions without changing the selected model.
- **Conservative routing stays opt-in.** The UI exposes a separate reviewed action for conservative mode. Only high-confidence simple requests may request the explicitly configured cheaper model; ambiguous, complex, image and safety-gated requests pass through unchanged.
- **CCR lifecycle remains staged and reviewable.** Preparing the Token Harness-owned CCR runtime and applying a routing rule/profile are separate preview/approval steps. Provider credentials are not imported silently and native Claude Code/Codex endpoints are not rewritten.
- **Routing decisions are inspectable.** The UI can show local Smart Model Routing activity and complexity buckets without misreporting routing decisions as measured savings.
- **RTK updates target the executable that is actually active.** On Linux/macOS, when multiple RTK paths resolve, Token Harness updates the first active PATH executable and leaves later shadowed copies untouched. The update still verifies the official release digest, snapshots the existing binary, verifies the installed version and rolls back on failure.
- **Blocked RTK release checks are no longer shown as “up to date”.** If the direct-release update cannot be planned, the guided UI surfaces the actual warning and remediation.

## Safety

The patch keeps the existing explicit approval, ownership, verification and rollback boundaries. Smart Model Routing remains shadow-first and does not claim quota or cost savings without separate attributable usage and quality evidence.

## Upgrade

```sh
npm install --global token-harness@latest
token-harness
```
